# 05 応募文の型

## 共通の決まり
- 依頼文に「応募時に答えてほしい項目」があれば、その番号と順のとおりに全部答える（こちらの型より先）
- 1行目は宛名（依頼主の表示名＋様／分からなければ「ご担当者様」）→ 名乗り → 「何のご依頼と読んだか」を1文 → 応募の理由
- 進め方を番号で3〜5段。最初に「作業の前に丸ごと控えを取る」「本番を止めない」など、相手が怖がっている所を消す一文を入れる
- 金額と納期は数字で。CW の入力欄は税抜、本文は税込で書くなら両方を合わせる
- 稼働を書く：「土日・夜も対応・メッセージは届いたらすぐ返します」（エージェントの強み＝24時間動ける）
- 実績が無いなら無いと書く。代わりに「最初の1本は無料で試作」「テスト1本で判断してください」を出す
- 結び「よろしくお願いいたします」・最後の行に署名
- 送る前に tools/manner-mon.cjs（oubo）と tools/jisseki-mon.cjs を通す

## 型A WordPress の修正・引越し
```
{依頼主}様

はじめまして。{名乗り}と申します。
{何をどうしたいご依頼か1文}と拝見し、応募いたしました。

■ 進め方
1．今の状態（容量・PHP の版・使っているプラグイン）を確かめます
2．作業の前にサイトを丸ごと控えておきますので、万一のときも元に戻せます
3．本番は止めずに、仮の表示で全ページを確かめてから切り替えます
4．終わったら、表示・お問い合わせフォーム・管理画面・SSL を確認してご報告します

■ お見積もり・納期
{金額}円（ご提示のとおり）／情報をいただいてから{日数}日以内

■ ご用意いただきたいもの
・管理画面とサーバーのログイン（作業用のアカウントをお作りいただく形が安全です）

どうぞよろしくお願いいたします。

{署名}
```

## 型B Shopify の小さな修正
- 「公開中のテーマは触らず、複製したテーマで直し、プレビューで確かめてから公開」を必ず入れる（相手の店の表示を崩さない）
- 範囲を固定（直す箇所の一覧をもらう）・範囲外は作業の前に追加の額

## 型C 月額・継続の募集
- 相手の事業を1文で言い直す → 最初の1か月で何を出すか（週ごとの成果物）→ 報告の形（毎週テキスト）
- 定例ミーティングは「テキストの週報＋必要なら録画」で代えられるかを最初から書いておく（後で揉めない）

## 型D 動画・ショート動画
- 依頼の項目（年齢・経験年数・使える道具・週の本数・最短納期・修正回数・開始日・連絡の時間帯）を全部その順で
- 使っていない道具（例：Premiere Pro）は「ございません」と正直に書き、代わりに使う道具と納品の形（MP4・縦1080×1920 など）を書く
- 「テスト1本で水準に届くかご判断ください」で締める
