# 02 場ごとの仕組み ── 並び方・選ばれ方

どの場も「検索の並び順」「応募の並び順」の計算式は公開していない（2026-11-03 に公式のヘルプ・認定の頁を当たって確かめた）。
だから、この章は3つに分けて書く。混ぜない。
- 【公式】場が自分で書いていること（出どころつき）
- 【実測】こちらが画面と記録で数えたこと（日付・母数つき）
- 【仮説】まだ確かめていないこと（確かめ方つき）

## クラウドワークス（CW）
### 【公式】プロクラウドワーカー（crowdworks.jp/lp/procrowdworker・2026-11-03 に開いた）
認定の条件（全部満たす・3か月ごとに審査）
| 項目 | 基準 | 期間 |
|---|---|---|
| 納品完了率 | 90%以上 | 直近1年（固定報酬のプロジェクト形式） |
| 総合評価 | 4.8以上 | 累計 |
| 獲得報酬額（月間） | 職種の部門で200位以内（エンジニア部門は100位以内） | 直近1年に1回以上 |
| スカウト数 | 5回以上（相手からの直接の仕事相談だけ） | 直近1年 |
| コミュニケーション評価 | 4.8以上 | 累計 |
| プロフィール・自己PR | 入力済み | 直近1年 |
認定されると：マークの表示／認定者だけの頁に載る／高単価・有名企業・発注確度の高い案件を優先して紹介される／メルマガやサイト内で取り上げられる。場の自社調べでは月間契約額 +19%・契約単価 +42%。
→ 検索の順位に効くとは書いていない。効くのは「紹介される」「目に付く」の側。

### 【実測】2026-11-03
- 案件の頁の「最近応募したクラウドワーカー」は応募の新しい順に10人まで見える。誰でも見られる
- 人気の小口は応募が速く積もる：WordPress の引越し 5,000円 → 掲載から数時間で応募55／Shopify の小さな修正 4,950円 → 7時間で応募42以上
- 月額の大きな募集（月20〜40万）は応募40前後
- 自分の応募一覧（/e/proposals）に「読まれた」の印は無い
- 依頼主の頁に「ありがとう」「総合評価」「募集実績」「完了率」「本人確認」が出る → 依頼主を選ぶ物差しに使える（評価なし・完了率が低い相手は落ちやすく、勧誘の型も多い）

### 【仮説】
- H-CW1 早い応募ほど読まれる（応募一覧の上にいる・依頼主が最初の数人で決める） → 確かめ方：掲載から30分以内に出した応募と、それ以降の応募で返事の率を比べる（各20件）
- H-CW2 依頼主の「募集実績」が多い相手ほど、評価0の応募者も読む → 確かめ方：募集実績10件以上と未満で返事の率を比べる

## ランサーズ
### 【公式】
- 自己紹介は1,000字まで・URL は書けない（保存のときに弾かれる）
- 提案文にも外の URL を書くと規約の案内が出る → 見本はランサーズのポートフォリオに登録して、その中で見せる
- ランク（レギュラー → ブロンズ → シルバー → ゴールド → プラチナ）・認定ランサーの制度がある。上がり方の細かい式は公式の頁では見つけられていない（二次の解説では、認定ランサーは毎月1日に審査・バッジと検索での優遇と書かれているが、公式では未確認）

### 【実測】2026-11-03
- パッケージ（出品）18本を出して、7日間の閲覧は全部 0（管理画面の数字）
  → 評価0・ランクが低いうちは、パッケージは検索に出ない／出ても下の方、と読める。**パッケージで待つより、提案（応募）で取りに行く**
- 「当選者が決定されました」は全提案者に届く（docs/03）
- コンペ（デザインなどの懸賞）は評価が無くても出せて、当たれば最初の評価になる

### 【仮説】
- H-L1 最初の評価が1件つくと、パッケージの閲覧が0でなくなる → 確かめ方：評価がついた日の前後7日の閲覧数を比べる

## SOKUDAN・Workship・スキルシフト（副業・業務委託の場）
### 【実測】2026-11-03
- 応募はできるが、どの場も返事は少ない（SOKUDAN 21件中 1件・Workship 9件中 1件・スキルシフト 12件中 0件）
- 週の稼働時間・会議への出席を求める募集が多い → 定例を断る線（docs/01）と合わないことが多い
### Workship の応募は「気になる！」＝一言の欄が無い（2026-11-04 実測）
- 募集の頁の「気になる！」を押すと、窓で①意欲（すぐに一緒に働きたい／話を聞いてみたい）②「募集内容を確認しました」を選んで送るだけ。応募文を書く欄は無い
- だから**プロフィールの自己紹介が応募文の代わり**になる。出す前に、その募集が求める語（例：n8n・LLM の出力をどう確かめるか）がプロフィールに入っているかを見て、無ければ足してから送る（または送った直後に足す）
- 送れたかは「自分からの気になる！」（/like/initiative）の一覧に会社名が載ったかで確かめる。押した直後の画面には完了の文が出ない
- 送った後の部屋の送信欄は閉じている（「企業からの返信が届くと、あなたからもメッセージが送れるようになります」）。こちらから一押しはできない＝勝負はプロフィールだけ。数日返事が無ければ見送りの見込み（事務局の自動文）
- 経歴なしで再現：する（場の作りの話）
### Workship の一覧の上位は「時間で働く形」がほとんど（2026-11-04 実測）
- 「おすすめ順」の1頁目で、まだ見ていなかった7件の本文を開いた。7件とも、次のどれかが条件に入っていた：オンライン定例・MTG への参加／週5・平日9〜18時の稼働や即レス／月60時間〜・週40時間／面談のあとで範囲を決める
- 依頼主と会議をしない・時間を約束しないで動くエージェントだと、7件とも合わない（7件とも見送り）
- やり方：一覧を開いたら、本文の「定例・MTG・稼働・週◯・月◯時間・平日・面談」の語だけを先に拾う。当たった物は読まずに外し、成果物（納品物）で区切られた募集だけを読む
- 経歴なしで再現：する（募集の形の話・経歴とは関係しない）

## 評価は上げるべきか（オーナーからの問い・2026-11-03）
結論：上げる。ただし**狙う分野と同じ種類の小さな仕事で**上げる。
- 理由1（公式）：CW の認定は評価4.8以上・完了率90%以上が条件。評価が無いと、この道に入れない
- 理由2（実測）：評価0のまま月額の大きな募集に出しても、返事は来るが採用まで行っていない（docs/08）
- 理由3：依頼主は「同じ種類の仕事の評価」を見る。関係ない分野（例：アンケート回答）の評価は効きにくい
- やり方：WordPress の修正・LP の手直し・Shopify の小さな修正など、狙う分野の小口に「低い値段＋見本の URL」で出す（無料の試作は規約で禁止・docs/05）

### ランサーズのパッケージを出すときの決まり（11/03 実測・経歴なしでも同じ）
- カテゴリごとに値段の下限が違う。「データ分析・作業自動化 ＞ データ入力」は 10,000円未満を入れると料金表の段で「10000円以上で入力してください」と出て進めない（5,000円で止まった）
- 中カテゴリによって「種別」の丸が必須になる（例：WordPress の中カテゴリは コンサルティング／ホームページ・サイト制作／カスタマイズ／LP制作・改善／パフォーマンス・SEO対策／セキュリティ管理／インストール・セットアップ／バグ修正／バックアップ・移行）。丸を選ばないと1段目から進まない
- 題名40字・副題60字・プランの説明80字まで。納期は 1〜7・10・14・21・30・45・60・75・90日から選ぶ
- 何を出すかは、マイページの「売れているパッケージ」を毎日貯めて選ぶ（11/03 時点の13件：HP制作・EC構築・商品登録代行・WordPress 更新代行・ショート動画・テロップ・Instagram 運用代行）
