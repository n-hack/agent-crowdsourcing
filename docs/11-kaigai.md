# 11 海外の場（日本の法人・AI エージェントが入れるか）

2026-11-03 調べ（一次＝公式ヘルプ・規約）。顔出し・電話・現地作業ができない前提で分けた。経歴の有無に関係なく同じに当てはまる。

## 入れる（顔を出さずに始められる）
| 場 | 要点 | 一次の出どころ |
|---|---|---|
| Fiverr | プロフィール写真は会社ロゴ可。出品前に個人／事業者の確認が要る（身分証＋自撮りは運営にだけ見える）。AI の使用は全カテゴリで可（生の出力・使い回しは不可・客が「AI なし」と言えば従う）。受注側の手数料 20%（二次） | help.fiverr.com 37332082211217（並び）／34998793899665（AI）／360010558598（写真） |
| Freelancer.com | 法人も利用者になれる（法人向けの有料アカウントが条件）。並びは評価（新しいほど重い）・支払い実績・応答の速さ・試験の成績・プロフィール。ロボットやスクレイパーでの利用は書面の許可なしに禁止 | freelancer.com/about/terms 33条／community の bid ranking guide（職員・2019） |
| Malt | 日本は対象国。登記の証明（3か月以内）・定款・実質的支配者の申告と英訳が要る。客は欧州 | help.malt.com 29511599491090 |
| Contra | 受注側の手数料は0%（無料会員は1回ごとに $15〜29） | contra.com/pricing |

## 判断が要る
- Upwork：プロフィール写真は顔が必須（代表者の顔写真と身分証があれば満たせる。先に手元に何があるかを確かめる）（support.upwork.com 360053305673）。出金は円で日本の銀行へ直接できる。公式の MCP の口で提案の下書きはできるが、送る前に人が確定する決まり。画面を自動で操る道具は即制限
- 評価0の印（Rising Talent）は「招待される」か「星4.8以上・12か月で $250 以上」＋本人確認＋出金方法の登録（11/01 更新）

## 入れない（生の面接・動画）
Toptal・Codeable・Arc（生の面接）／Braintrust（一方向の動画）／99designs はロゴ・イラスト・アイコンに生成 AI 禁止

## どの場でも共通で禁止
- 評価のための無料の仕事を頼む・申し出る（Upwork・CW 規約23条(31) の仮払い前の作業も同じ向き）
- 契約前の連絡先の受け渡し・場の外での取引
- 1人で複数アカウント
