# 00 最初に読む ── このリポジトリのゴールと使い方

## ゴール
**どの N-Hack のエージェントでも、このリポジトリを読むだけで、クラウドソーシングで最短で稼げるようになること。**
- 属人化しない：オーナーの経歴・人脈・知名度に頼らない。経歴が強いオーナーでも弱いオーナーでも、同じ手順で同じ結果に近づける
- 作業はエージェントがやる：探す・選ぶ・応募文・やり取り・作業・納品・記録。オーナーがやるのは登録・本人確認・面談・お金の最終確認だけ

## 経歴に頼らない理由（実測）
このリポジトリを作ったアカウントは、オーナーの経歴（大学院・テレビ局・独立・出版など）をプロフィールに全部書いていた。それでも評価0のうちは、約120件の応募で契約0件だった（docs/08）。
→ **経歴は「選ばれる決め手」にならなかった。** 決め手になりうるのは、どのオーナーでも同じに揃えられる次の物：
1. 評価（同じ種類の小さな仕事で1件目を取る）
2. 開ける見本（架空の題材で作った実物の URL・docs/07）
3. 速さ（出てすぐ応募・返事は即時・納品は最短）
4. 応募の少ない募集を選ぶ（応募100人超の募集では、こちらは中央で183人目だった・docs/02）
5. 最初の1本は無料で試作する（相手の失敗の怖さを消す）
経歴は「あれば1行足す」扱いにする。応募文の型（docs/05）は経歴の行が無くても成り立つように書いてある。

## 使い方（エージェント向け）
1. まず `node tools/nhack-mon.cjs` を走らせる。🔴 なら、このリポジトリの道具は使えない（N-Hack のエージェント専用）
2. `config/profile.example.json` を `config/profile.json` に写し、名乗りと署名を入れる
3. docs/01〜09 を順に読む
4. 1日の回し方（README）どおりに回し、分かったことを docs/10 に足す

## 使える範囲
- N-Hack のエージェント（N-Hack のプラグインが入った Claude Code）だけ。道具は先頭で N-Hack の門（tools/nhack-mon.cjs）を通り、それ以外の環境では止まる
- 内容の再配布・公開・販売はできない（LICENSE）
