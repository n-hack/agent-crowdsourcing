# 00 最初に読む ── このリポジトリのゴールと使い方

## ゴール
**どの N-Hack のエージェントでも、このリポジトリを読むだけで、クラウドソーシングで最短で稼げるようになること。**
- 属人化しない：オーナーの経歴・人脈・知名度に頼らない。経歴が強いオーナーでも弱いオーナーでも、同じ手順で同じ結果に近づける
- 作業はエージェントがやる：探す・選ぶ・応募文・やり取り・作業・納品・記録。オーナーがやるのは登録・本人確認・面談・お金の最終確認だけ

## 経歴に頼らない理由（実測）
このリポジトリを作ったアカウントは、オーナーの経歴（大学院・テレビ局・独立・出版など）をプロフィールに全部書いていた。それでも評価0のうちは、約120件の応募で契約0件だった（docs/08）。
→ **経歴は「選ばれる決め手」にならなかった。** 決め手になりうるのは、どのオーナーでも同じに揃えられる次の物：
1. 評価（同じ種類の小さな仕事で1件目を取る）
2. 開ける見本（架空の題材で作った実物の URL・docs/07）
3. 速さ（出てすぐ応募・返事は即時・納品は最短）
4. 応募の少ない募集を選ぶ（応募100人超の募集では、こちらは中央で183人目だった・docs/02）
5. 相手の失敗の怖さは「自分で作った見本の URL」と「初回だけ下げた料金」で消す。🔴 無料の試作・仮払い前の作業はしない（CW 規約23条(31)で禁止）
経歴は「あれば1行足す」扱いにする。応募文の型（docs/05）は経歴の行が無くても成り立つように書いてある。

## 使い方（エージェント向け）
1. まず `node tools/nhack-mon.cjs` を走らせる。🔴 なら、このリポジトリの道具は使えない（N-Hack のエージェント専用）。N-Hack のプラグインが入っていないときは、次の2行で入れてから Claude Code を起こし直し、もう一度走らせる
   ```
   claude plugin marketplace add <このリポジトリの持ち主>/nhack-discord
   claude plugin install nhack-discord@nhack-plugins
   ```
   `<このリポジトリの持ち主>` は、このリポジトリを取ってきた GitHub の組織名（`git remote get-url origin` の github.com の次の名前）
2. 人がやる初期構築（登録・本人確認・口座・メールと予定・連絡ツール）が済んでいるかを docs/15 の確かめの行で見る。🔴 の段は人に1行で頼む
3. 下の「問診票」をオーナーに渡して答えをもらい、`config/profile.example.json` を `config/profile.json` に写して入れる
4. docs/01〜09 を順に読む
5. 1日の回し方（README・docs/12）どおりに回し、分かったことを docs/10 に足す

## 問診票（名乗り・署名をオーナーから受け取る）
名乗り・署名・名前は、応募文と返事に入り、相手はその名前の人とやり取りします。エージェントが作ったり推したりしない。見本の「◯◯」のままだと下書きの道具（oubo-shitagaki.cjs）が rc=2 で止まるのは、そのための門です。
オーナーへは次の1通をそのまま送り、答えをもらう（プロフィールに使う残りの欄は docs/16 の問診票。同じ時に一緒に渡してよい）。

```
クラウドソーシングの応募と返事に使うお名前を教えてください。相手の方には、この名前のご本人として届きます。
1 お名前（本名・漢字）：
2 会社名（法人で受ける場合だけ・個人なら空欄）：
3 応募文の名乗り（例「姓名」「株式会社〇〇の姓」の形）：
4 署名（文の最後に入る1〜2行。例「姓名」だけ・会社名と姓名の2行）：
5 各場での表示名（登録した表示名と同じもの）：
6 自社で募集を出している場合、その依頼主の表示名（自分の募集に応募しないため・無ければ空欄）：
```
入れる先（config/profile.json）
| 問診票 | profile の欄 |
|---|---|
| 1 | 名前 |
| 2 | 会社名（空なら空のまま） |
| 3 | 名乗り |
| 4 | 署名 |
| 1・2・5 | 自分の名前の印（返事の見張りが「最後に書いたのが自分か」を見分ける語。名前・会社名・表示名を並べる） |
| 6 | 自社の依頼主ID |
| ─ | メール … docs/15 段1の専用アドレス（場の登録に使った物） |

### 答えが来るまで（試しの間）の扱い
- 名乗り・署名は空けて待つ。仮の名前を作って入れない（作った名前の下書きが、後で本物と混ざって出るのを防ぐ）
- その間も、巡回と門（docs/12 の段1・2）はオーナーの値が無くても回る。`bash tools/mawasu.sh --no-browser` は段3（応募文）で止まるが、止まるまでの巡回と門の結果は置き場に残る（docs/12）
- 道具の試しをしたいときは、置き場を本番と分け（`CS_DATA=<試しの置き場>`）、`--go` を付けない。試しの置き場は答えが来たら消す
- 答えを入れたら `node tools/settei.cjs` で設定の道と置き場を確かめ、`bash tools/mawasu.sh --no-browser` を1回回して段3が通る（「3 応募文 ✅ 下書き N 件」）ことを見る

## 使える範囲
- N-Hack のエージェント（N-Hack のプラグインが入った Claude Code）だけ。道具は先頭で N-Hack の門（tools/nhack-mon.cjs）を通り、それ以外の環境では止まる
- 内容の再配布・公開・販売はできない（LICENSE）
