# 06 返事の型とビジネスマナー

## 即レス（いちばん効く）
- 届いたらその場で返す。中身に時間が要る時も、まず「拝見しました。◯時までにお返しします」
- 根拠：ビジネスメールは24時間以内に返信が来ないと遅いと感じる人が約7割（日本ビジネスメール協会 実態調査2020・二次の記事経由）／3時間以内に返信がほしい人が4割強（yaritori 調査2025）
- エージェントは24時間動ける。夜・土日の即レスがそのまま強みになる

## マナーの決まり（出どころ：文化審議会答申「敬語の指針」平成19年 ほか）
1. 1行目に宛名（「◯◯様」「ご担当者様」・会社あては「御中」・御中に様は重ねない）
2. 名乗り（初めては「と申します」）
3. お礼か挨拶（「ご連絡ありがとうございます」）
4. 要旨を最初の1〜2文。質問には番号を振って全部答える
5. 結び「よろしくお願いいたします」
6. 最後の行に署名
7. 二重敬語を使わない（おっしゃられ／拝見させていただ／お伺いさせていただ など）
8. 「させていただく」は相手の許可と恩恵がある時だけ。1通に3回以上は多い
9. 「了解しました」でなく「承知しました」
10. くだけた語尾・記号・絵文字を使わない（相手が使っていても）
11. 遅れたら最初にお詫びを1文
→ tools/manner-mon.cjs（henji）が 1・2・5・6・7・9・10 を機械で止める

## 返事の型
① 実績・ポートフォリオを見せてほしい
「制作の見本をお送りします。（見本の名前と1行）お客様のサイトは守秘のため公開していないものが多く、見本は自社で作ったものをお出ししています。近い内容の見本がございましたら、URL をお送りします。」（🔴 無料・無償の試作の申し出は書かない：CW 規約23条(31)）

② 採用前にオンラインで話したい
「ぜひお話しさせてください。候補の日時を3つほどいただけましたら合わせます。」→ オーナーの予定の空きを見てから返す

③ 採用後の定例ミーティング
「進捗は毎週テキストでまとめてご報告し、ご質問には当日中にお返しする形で進めております。定例は設けず、その分を制作に充てていますので、テキストでのやり取りでお願いできますでしょうか。画面を見ながらの説明が要る節目は、操作を録画した動画でお送りします。」→ それでも必須なら辞退

④ 見積もりの内訳 … 項目ごとの額・修正の回数・範囲が変わる時は作業の前に額を出す
⑤ 値下げ … 「◯◯を外す形で◯円にできます。品質を下げての値引きはしておりません」
⑥ 納期を早めたい … 「◯日までの公開が可能です。そのために素材を◯日までにいただけますと確実です」
⑦ AI を使うのか … 「下書きや確認に AI を使い、最終の確認は人の目で行っています。顧客情報やパスワードなどの機密は AI のサービスに入力しません」
⑧ 秘密保持契約 … 「結べます。場の機能でお願いいたします」
⑨ ログイン情報を渡したい … 「メッセージで直接お送りいただかず、作業用のアカウントを作っていただく形が安全です（終わったら消していただけます）」
⑩ 不採用 … 「ご検討いただきありがとうございました。また機会がございましたら、よろしくお願いいたします。」（お礼は必ず返す・次に繋がる）
⑪ 購入された（パッケージ） … お礼 → 進めるのに要る3点 → 「本日中に、何をどう作るかと納品日を文章でお送りします」
⑫ 事前の相談「こういうこともできますか」 … できる物は近い段と追加の額／できない物はその場で「できません」

## 返事待ちへの一押し（2026-11-03 から試し中）
- 応募から1〜2日返事が無い相手に、「見本の URL つき」の短い一押しを1回だけ（無料の試作は規約で禁止なので付けない）（催促の言葉は使わない）
- 結果は docs/08 に足す

## 面談が決まったら（前日までに）
- 面談の1枚（相手と案件の要点・聞かれそうなことと答え・こちらから聞くこと・気をつける線）を作り、出る人に渡す
- 1枚に「〜の環境はある」と書いたら、その環境で実際に1回動かしてから渡す。書いただけの「ある」は面談で崩れる（11/04 実例：「Windows の作業機はある」と書いていたが、Python が入っておらず Store の入口だけだった → 入れて、案件と同じ形〈PyInstaller で exe〉を1本作って動くまで確かめてから1枚を直した）
- CW で面談（ウェブ会議）をするときは、前に「サービス外連絡申請」を出す。審査は最大2営業日・1件に1回
  - 相手が申請したときも審査は事務局。こちらに承認ボタンは出ない（相談の画面に「申請中（申請者：相手）」と出るだけ）。承認の通知が来るまで、相手が貼った予約の頁（Google カレンダーの予約など）で枠を取らない。先に「申請の承認後に日程をお返しします」と1通返し、空きは持ち主の予定と相手の予約の頁の両方で先に見ておく（2026-11-04 実例・出どころ：CW ヘルプ「サービス外連絡申請について」）。経歴なしでも再現：する
