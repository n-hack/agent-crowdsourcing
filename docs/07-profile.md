# 07 プロフィール・ポートフォリオ・パッケージ ── 売れている人の型を写す

写すのは「型（並べ方・題の付け方）」だけ。文章・画像・デザインそのものは写さない（著作権）。比べる相手は「実績の数が多い＝売れている人」だけ。

- ありがとう 741〜1,347・評価 4.8〜4.9・評価件数 409〜1,089
- プロフィール文を見出しで区切る：▼ポートフォリオ（公開中の実物のサイトの URL を種類ごとに）／▼可能な業務／▼使用言語／▼活動時間（毎日◯時間・最短◯日）／▼連絡手段
- **画像の作品集より、開ける実物のサイトが先**。見本を公開の置き場（無料の静的ホスティングなど）に置き、URL で見せる
- 見本は「制作サンプル・架空」と明記する

## 経歴のテンプレート
経歴が無いオーナーでもそのまま使える型は [templates/keireki.md](../templates/keireki.md)。経歴の欄を「請け負える仕事・見本の URL・働き方」で埋める。

## プロフィール文に入れる物（評価0の時期）
- 【はじめての方へ】初回は通常より下げた料金でお受けします（見本はポートフォリオからご覧ください）
- 【稼働】毎日（土日・夜も）・返信は多くが1時間以内・納品は最短当日〜
- 経歴は「確かめた事実」だけから書く。数字は出してよいが、出どころの無い数字は書かない
- ランサーズは1,000字まで・URL 不可（見本はポートフォリオ欄へ）
- ランサーズのポートフォリオの題名の欄は「〜を作成し」で止める。場が後ろに「ました」を足して出すので、「作成しました」まで書くと「作成しましたました」になる。登録したら公開の頁を開いて題名を目で確かめる（11/04 に6件で二重になり直した・経歴なしでも再現：する）

## ポートフォリオを「納品物」で厚くする（11/04）
- 身内や自社に、本当に使える小さな道具を納品し、その物を見本の頁＋ポートフォリオにする。書き方は「個人のお客様へ納品」。使い続けているかは書かない（使っている物だけ「運用中」）
- 🔴 場の中で身内に発注して評価を作るのは規約で禁止。納品は場の外で行う
- 選び方は高単価の募集から逆算：応募の記録で10万円以上・月額の募集を並べ、多い型（業務の自動化・AI で判定・データの集計・小さな管理画面）を作る
- 1本30分前後・中身は「書いた事は本当に動く」まで。見せ方（見本の頁・画面の画像・動かした記録・わざと壊した時の記録）に力を入れる
- AI を使う道具は、AI の作り話を式で止める印を必ず入れる（例：FAQ に無い金額・言い切りは赤）。「AI に任せきらない」が見本の売りになる
- 経歴なしでも再現するか：する（道具は誰でも作れる）
