# 13 面談の前に人へ渡す1枚

> オーナーの指示：面談は人がやる前提でよい。出る人がどんな人でも同じに話せるよう、事前に話す情報を1枚にして渡す（高単価は面談がないと決まりにくい）。

- 誰が出ても同じに話せるよう、面談の前日までにこの1枚を作って面談に出る人へ渡す。エンジニアでなくても読める言葉で書く
- 中身は応募文と相手ごとの台帳（<置き場>/aite/）に書いた事実だけ。無い実績・数字は足さない
- 元にした実例：家庭向けアプリの開発の面談（30万円で決まった）の手元メモ。経歴なしでも再現：する（話す中身は応募文と台帳から写すだけ）

## 型

### 0. 1行でいうと
- 先方は何に困っていて、こちらは何を、いくらで、いつまでに出すと応募したか（1行）

### 1. 面談の基本
- 日時・長さ・入り方（Meet／Zoom の URL）・先方の名前・こちらの名乗り（会社名と名前）
- 応募で出した額・納期・稼働（数字はそのまま。応募文から写す）

### 2. 先方のこと（調べて分かった事実だけ）
- 募集の要点（3行）／会社か個人か・評価の数・募集の実績
- 先方が気にしていそうな所（募集文の「必須」「歓迎」「注意」から）

### 3. こちらから最初に話すこと（2分）
- 名乗り → 応募で書いた強み1つ → 進め方（最初の小さな段 → 確認 → 残り）
- 読み上げてよい文の見本を1つ置く

### 4. 伺うこと（ここで見積もり・範囲が決まる）
- 番号つきで5〜7個。答えをメモする欄を空けておく

### 5. 聞かれそうなことと答え
- 「実績は？」「いつから？」「週何時間？」「いくら？」「AI を使う？」「ほかの仕事との兼ね合い？」
- 答えは応募文と台帳に書いた事実だけ。無い物は「無い」と言う

### 6. 値段と範囲の線（その場で決めない）
- 応募の額・上げてよい上限・下げてよい下限（下限は事前に決めた物だけ）
- 範囲が広がったら「範囲を書面にまとめて当日中にお送りします」で持ち帰る

### 7. 言ってはいけないこと・してはいけないこと
- 応募文に無い実績・数字・資格を足さない／できない事を「できる」と言わない
- その場で金額・納期を新しく約束しない（持ち帰る）
- 勧誘の印が出たら丁寧に辞退：①選考なのに長い ②稼げる・身につくの話が先 ③講座・教材・費用 ④LINE など外へ誘導（1円も払わない）

### 8. 面談のあとにすること（エージェント側）
- その日のうちにお礼＋決まったこと・持ち帰ったことの書面を送る（台帳に書く）
- 契約の形（CW の契約・仮払い）を確かめてから着手

## 見本（実際に作った1枚・名前・会社名・URL・案件番号は伏せた）

### 面談の前の1枚：◯月◯日（月）11:00〜12:00　A社（◯◯様）一次面談

#### 0. 1行でいうと
- 「データ入力・フォーム登録・定型文のチャット対応」の在宅スタッフ募集（8名・応募127人）に、月5万円から・当日中に返事、で応募。55,000円（税込）を提示

#### 1. 面談の基本
- 日時：◯月◯日（月）11:00〜12:00（60分の「一次面談」）
- 入り方：Google Meet（URL は面談に出る人の予定に登録済み）
- 先方：A社の◯◯様（CW の表示名は別の名前）
- 名乗り：B社の◯◯です
- 予約の名前の欄が崩れて届いていた → 部屋で正しい名前を送り済み。冒頭で一言「予約のお名前が崩れていて失礼しました」

#### 2. 先方のこと（分かっている事実）
- 募集：事業のサポート。指定リストの入力・専用フォームへの登録・定型文のチャット対応・マニュアルに沿った案内・確認と更新。電話と営業なし
- 報酬の書き方：月5万〜35万円（業務量と継続で上がる）
- 依頼主：評価0件・募集の実績1件（この案件）・本人確認済み
- 応募時の質問の1つが「将来いくら稼ぎたいか」＝副業スクールの勧誘でよく使われる聞き方。🔴 下の 7 を必ず見る

#### 3. こちらから最初に話すこと（2分・読み上げてよい）
「B社の◯◯です。本日はお時間ありがとうございます。会社として社内の事務や集計を自分たちで回していて、リストの入力やフォームへの登録は、手順を決めて件数と中身を照らしてからお渡しする形でやっています。まずは月5万円ほどの量から始めて、任せていただける範囲で増やせればと思っています。」

#### 4. 伺うこと
1. 最初にお任せいただく作業の中身（リストは何件・何の情報・どの形で届くか）
2. 専用フォームはどこの何か（アカウントは先方が用意するか）
3. 定型文のチャット対応の相手は誰か（お客様か・社内か）、1日何件ほどか、返す時間帯の決まりはあるか
4. 報酬の決め方（件数か時間か固定か）と、最初の1か月の量
5. 契約は CW の中で結ぶ形でよいか
6. 研修やマニュアルは無料か（🔴 費用が出たらその場で辞退）
7. いつから始められるか

#### 5. 聞かれそうなことと答え
- 実績は？ → 社内の事務・集計・明細の転記と突き合わせを日常的にしている（応募文に書いたとおり。数字は足さない）
- 週何時間？ → 平日の日中に、ご依頼の量に合わせて確保できる
- AI を使う？ → 入力の確かめ（件数と中身の照合）に道具を使うことはある。お客様の情報を外の道具に出さない
- 個人か会社か？ → 株式会社として受ける。請求も会社から
- いくら目指す？ → 応募で答えたとおり「まず月5万円ほどから」

#### 6. 値段と範囲の線（その場で決めない）
- 応募の額：55,000円（税込）。月5万円の量から
- その場で新しい金額・量は約束しない →「作業の中身と量を書面でいただければ、当日中にお返事します」で持ち帰る

#### 7. 言ってはいけないこと・してはいけないこと
- 🔴 勧誘の印が1つでも出たら、丁寧に辞退して終える（1円も払わない・カード番号や口座を伝えない）
  ①選考なのに長い説明が続く ②仕事より「稼げる・身につく・自由な働き方」の話が先 ③講座・教材・サポート費・初期費用の案内 ④LINE・外のサイト登録への誘導
- 辞退の一言：「今回は事務作業のお仕事として伺っていましたので、講座などのご案内でしたら辞退させてください。お時間ありがとうございました。」
- 応募文に無い実績・数字を足さない

#### 8. 面談のあと（エージェントがやる）
- 当日中に CW の部屋へお礼＋決まったこと・持ち帰ったことを書面で送る（相手ごとの台帳に書く）
- 勧誘だった場合：台帳と docs/10 に「印の種類」を書き、同じ型の募集を門で止める

#### 9. 面談の打診が来たら、仕事に近い見本を先に作って送る（エージェントがやる）
- 打診や日程の調整の便が来た時点で、募集の本文の「肝」（例：AI をブラックボックスにしない・根拠を説明できる）に答える小さな見本を作る。中身は架空のデータで作り、実在の社名・個人情報は入れない
- 見本には、測った数字を必ず添える（例：手で付けた正解と突き合わせた正答率・同じ設定で2回回して揺れが無いか・費用）。弱い所も隠さず書く（「実データでは数字は下がる前提」など）
- 公開の頁に載せ、部屋では URL と数字を3〜4行で伝える。まだ作業はしていない段なので「無料で作業します」とは書かない（規約で仮払い前の作業は禁止の場がある）。見本は自分の制作物として見せる
- 実例：顧客の声の分析アナリストの募集（月70〜100万）で、面談の候補を出した便のあとに見本（架空197件・正答率80%→84%・揺れ0件）を送り、その日のうちに面談の日時が決まった（n=1・見本が決め手だったかは未確認）
- 経歴が無くても再現するか：する（見本は募集の本文だけから作れる）。経歴がある場合は、近い経験を1行だけ添える
