# 経歴・プロフィールのテンプレート（経歴が無いオーナーでもそのまま使える）

このリポジトリのオーナーの決め（2026-11-03）：「経歴はエージェントができそうなことでテンプレを用意しておけば、経歴が無い人でも、エージェントができることは経歴に書いても大丈夫」。
→ 経歴の欄は「人の職歴」ではなく「**このアカウントで請け負える仕事と、その証拠**」で埋める。

## 書いてよい／書かない（ここだけは守る）
| 書いてよい | 書かない |
|---|---|
| できる作業と使う道具（WordPress・Shopify・GAS・Python・ffmpeg など） | 無い「実務経験◯年」・無い職歴 |
| エージェントが実際に作った見本（架空の題材・「制作サンプル」と明記）の URL | 実在しない取引先・実績の件数・売上の数字 |
| 納期・対応の時間帯・返信の速さ（実際に守れる物だけ） | 「必ず成果が出る」などの約束 |
| 「AI を使って作業し、最終の確認をしています」 | 人が手作業しているように見せる書き方 |
理由：無い年数・実績を書くと、場の規約（虚偽の登録）と景品表示法（優良誤認）に当たる。見本と「できること」なら、うそにならずに比べてもらえる。

## テンプレート（CW のプロフィール欄・1,000字前後に収まる形）
```
はじめまして。{名乗り}です。
Web制作・業務の自動化・SNSの投稿づくりを、早く・ていねいにお受けしています。

【はじめての方へ】
最初の小さな段（最初の数件・1ページ分）を仕上げてお見せし、形を確かめていただいてから残りを進めます。見本はポートフォリオからご覧ください。

【お受けできること】
▼Web … WordPress の修正・PHP 更新・サイトの引越し／LP の制作（PC・スマホ対応）／Shopify の構築と修正
▼自動化 … Google スプレッドシートと GAS／Python でのデータ集め・集計・レポートの自動化
▼SNS・動画 … Instagram の投稿画像・縦型ショート動画の編集（テロップ・BGM・効果音）
▼文章・資料 … 記事・台本・提案資料・PDF→Word の起こし直し

【見本（実際に作った物・制作サンプル）】
・{見本の一覧の URL}
（ランサーズは URL を書けないので、見本はポートフォリオ欄に入れる）

【進め方】
1．ご要望を伺い、作る物・納期・金額を文章でお出しします
2．作業の前に、元のデータを丸ごと控えます（何かあっても戻せます）
3．途中の確認ページをお見せしてから仕上げます
4．納品後の小さな直しは無料です

【稼働】
毎日（土日・夜も）対応・メッセージは届いたらすぐにお返しします・納品は最短当日〜

【使う道具】
WordPress／Shopify／HTML・CSS・JavaScript／GAS／Python／ffmpeg／Canva 以外の画像の作成／生成 AI
作業には AI を使い、最終の確認をしてからお渡しします。お客様の機密は AI のサービスに入力しません。
```

## 経歴があるオーナーは
上の型に、確かめた事実だけを1〜3行足す（「◯◯で◯年」「出版」など）。経歴が無くても型は成り立つ。
