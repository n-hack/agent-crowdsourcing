# 見本1 会社リストの CSV（営業先リストの作成）

見本として作ったもの（架空の依頼の題材）。お客様・実績・金額を作らない。
実物：[samples/01-kaisha-list-csv/](../../samples/01-kaisha-list-csv/)（作って動かした物・出力は README に貼ってある）


## 題（業種＋目的の形）
- ポートフォリオの題：製造業向け営業リストの作成（公開の法人データから地域と業種で絞った CSV）
- ランサーズの題名の欄：「公開の法人データから製造業の営業リストを作成し」で止める（場が「ました」を足すので「作成しました」まで書かない）

## 中身
- 公開されている法人のデータ（例：国税庁の法人番号公表サイトの全件データ。使ってよい範囲と出典の書き方は、取る前にサイトの利用規約を読んで確かめる）から、1つの県と1つの業種の語で絞った会社の一覧
- 列：法人番号・会社名・所在地・郵便番号・取得元・取得日
- 重なりを消す（同じ法人番号は1行）・住所の表記をそろえる（全角半角・丁目の書き方）
- 個人の名前・個人のメールアドレス・電話番号は入れない（公開の情報でも、営業の連絡先として集めない）
- 渡す物：CSV（UTF-8・Excel で文字化けしない BOM 付きも）・何件から何件に絞ったかの数え方1枚

## 作り方（エージェントへそのまま渡す指示文）
```
ポートフォリオの見本として、公開の法人データから営業リストの CSV を作ってください。
1. 使うデータの出どころの頁と利用規約を開き、取ってよいこと・出典の書き方を確かめてから取る。確かめられなければ止めて報告する
2. 県を1つ、業種の語を1つ決め、会社名か事業の内容にその語を含む法人だけに絞る
3. 列は 法人番号・会社名・所在地・郵便番号・取得元・取得日。同じ法人番号は1行にする。住所は全角半角をそろえる
4. 個人の名前・メールアドレス・電話番号は入れない
5. 元の件数、絞った後の件数、重なりで消した件数を、式つきで1枚に書く（例：wc -l の値と、絞った語）
6. CSV は UTF-8 と BOM 付きの2つを出し、Excel で開いた画面の画像を1枚撮る
7. 頁の頭に「見本として作った物（架空の依頼）」と書く。お客様の名前・金額・納品の実績は書かない
```

## ポートフォリオの欄の説明文（相手が読む文・{料金の下限} は問診票から）
```
公開されている法人のデータから、県と業種で絞った営業リストの CSV を作った見本です。題材は架空の依頼で、実在のお客様の物ではありません。
同じ法人番号は1行にまとめ、住所の表記をそろえ、元の件数から何件に絞ったかを数え方つきでお渡しします。個人の名前や電話番号は集めません。
同じ規模のリストをお受けする場合の目安は、{料金の下限}円からです。
```

## 見せ方
- 公開の頁に、先頭20行の表・件数の数え方・出典を載せる（全件は載せない）
- 画面の画像：Excel で開いた画面1枚（文字化けしていないことが見える物）
- 動かした記録：取って絞るまでの打鍵と件数の出力（鍵や置き場のパスは消す）
- 金額の欄が要る場では「同じ規模をお受けする場合の目安」と書いて入れる（0円では保存できない場がある・docs/07）
