# 見本5 データ取得の小道具（公開の頁から表へ）

見本として作ったもの（取得の練習用に公開されている頁が相手）。お客様・実績・金額を作らない。

## 題（業種＋目的の形）
- ポートフォリオの題：書店向け商品一覧の取得（公開の頁から題名・値段・在庫を毎日スプレッドシートへ）
- ランサーズの題名の欄：「公開の頁から商品一覧を取得してスプレッドシートに書く道具を作成し」で止める

## 中身
- 相手：取得の練習用と明記されている公開の頁（例：books.toscrape.com）か、使ってよいと書かれた公開の API。実在のお店の頁は、見本では取らない
- 出力：題名・値段・在庫・頁の URL・取った日時の CSV（スプレッドシートにも書ける）
- 作法：robots.txt と利用規約を先に読む・1頁ごとに間を空ける・前回と比べて増えた物と消えた物を出す
- 止まる形：頁の形が変わって列が空になったら、空のまま出さずに止まる（rc を分ける）

## 作り方（エージェントへそのまま渡す指示文）
```
ポートフォリオの見本として、公開の頁から商品の一覧を取る小さな道具を作ってください。
1. 相手は取得の練習用と明記された公開の頁にする。robots.txt と利用規約を読み、取ってよいことを確かめてから始める
2. 題名・値段・在庫・URL・取った日時を CSV に書く。1頁ごとに1秒以上空ける
3. 前回の CSV があれば、増えた物と消えた物を出す
4. 列の中身が空の行が半分を超えたら、頁の形が変わったとみなして rc=3 で止まる（空の CSV を正常として出さない）
5. わざと探す場所をずらして rc=3 で止まることを確かめ、その出力も残す
6. 頁の頭に「見本として作った物（練習用の頁が相手）」と書く
```

## ポートフォリオの欄の説明文（相手が読む文・{料金の下限} は問診票から）
```
公開の頁から商品の一覧を取り、スプレッドシートに書く小さな道具の見本です。取得の練習用に公開されている頁を相手にしました。
前回と比べて増えた物と消えた物を出し、頁の形が変わって中身が取れなくなったときは、空の表を出さずに止まります。取る前に、相手の頁の決まりを確かめます。
同じ規模の道具をお受けする場合の目安は、{料金の下限}円からです。
```

## 見せ方
- 公開の頁：取れた CSV の先頭20行・取った件数・前回との差
- 画面の画像：スプレッドシートに書かれた様子1枚
- 動かした記録：正常な回と、わざと壊して止まった回の2つ
- 金額の欄が要る場では「同じ規模をお受けする場合の目安」と書いて入れる
