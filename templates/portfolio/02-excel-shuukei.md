# 見本2 Excel の自動集計（月次の売上レポート）

見本として作ったもの（架空の店と架空の数字）。お客様・実績・金額を作らない。
実物：[samples/02-excel-shuukei/](../../samples/02-excel-shuukei/)（作って動かした物・出力は README に貼ってある）


## 題（業種＋目的の形）
- ポートフォリオの題：小売店向け月次売上レポートの自動集計（毎日の CSV から店別・商品別の表とグラフ）
- ランサーズの題名の欄：「毎日の売上 CSV から月次レポートを自動で作る仕組みを作成し」で止める

## 中身
- 入力：毎日1つ出る売上の CSV（日付・店・商品・数量・金額）を30日分。数字は乱数で作った架空の物
- 出力：1つの Excel ファイルに、月の合計・店別・商品別の表と、日ごとの折れ線グラフ
- 動かし方：フォルダに CSV を置いて1コマンド（Python と openpyxl）。Google スプレッドシートで使う版は GAS で同じ形
- 確かめ：元の CSV の合計と、表の合計が1円も違わないことを最後に出す（違えば止まる）

## 作り方（エージェントへそのまま渡す指示文）
```
ポートフォリオの見本として、売上の CSV から月次レポートの Excel を作る道具を作ってください。
1. 架空の店3つ・商品10個の売上の CSV を30日分、乱数で作る（実在の店名・商品名は使わない）
2. フォルダの CSV を全部読み、月の合計・店別・商品別の表と、日ごとの折れ線グラフを1つの xlsx に書く
3. 最後に、元の CSV の金額の合計と、表の合計を並べて出す。合わなければ rc=1 で止まる
4. わざと1つの CSV の金額を壊して、止まることを確かめ、その出力も残す
5. 使い方を3行で書く（置く場所・打つコマンド・出てくる物）
6. 頁の頭に「見本として作った物（架空の店と数字）」と書く
```

## ポートフォリオの欄の説明文（相手が読む文・{料金の下限} は問診票から）
```
毎日の売上の CSV から、月の合計と店別・商品別の表とグラフを1つの Excel に自動で作る見本です。店も数字も架空です。
最後に元の CSV の合計と表の合計を突き合わせ、1円でも違えば止まる作りにしています。Google スプレッドシートで使う形にも直せます。
同じ規模の集計をお受けする場合の目安は、{料金の下限}円からです。
```

## 見せ方
- 公開の頁：出来上がった Excel の画面の画像2枚（表とグラフ）・使い方3行・合計の突き合わせの出力
- 動かした記録：正常な回と、わざと壊した回の2つ（壊した回で止まるのが売りになる）
- xlsx そのものも置く（数字は架空と頁にも書く）
- 金額の欄が要る場では「同じ規模をお受けする場合の目安」と書いて入れる
