# 見本3 問い合わせ FAQ の自動返答（返事の下書きと止める印）

見本として作ったもの（架空の歯科医院の FAQ）。お客様・実績・金額を作らない。

## 題（業種＋目的の形）
- ポートフォリオの題：歯科医院向け問い合わせ返答の下書き（FAQ から答え、FAQ に無い金額と言い切りは止める）
- ランサーズの題名の欄：「歯科医院の FAQ から問い合わせの返事の下書きを作る仕組みを作成し」で止める

## 中身
- 入力：架空の歯科医院の FAQ（20問・診療時間・予約の取り方・駐車場・支払い方法など）と、届いた問い合わせの文
- 出力：返事の下書きと、使った FAQ の番号
- 止める印（赤）：下書きに FAQ に無い金額が出た／「必ず」「絶対」「治ります」など言い切りが出た／FAQ のどれにも当たらない問い合わせ。赤の下書きは送らずに人へ回す
- AI に任せきらない作りが売りになる（docs/07）。止める印は AI ではなく式（文字の照らし合わせ）で当てる

## 作り方（エージェントへそのまま渡す指示文）
```
ポートフォリオの見本として、FAQ から問い合わせの返事の下書きを作り、危ない下書きを止める仕組みを作ってください。
1. 架空の歯科医院の FAQ を20問作る（実在の医院名・住所・電話番号は使わない。診療の効果を約束する文は入れない）
2. 問い合わせの文を受け、近い FAQ を選び、その FAQ の文だけを使って返事の下書きを作る。使った FAQ の番号を下書きの下に出す
3. 下書きの検査を式で入れる：FAQ に無い金額（数字＋円）・言い切りの語（必ず・絶対・治ります・保証）・どの FAQ にも当たらない、のどれかがあれば赤にして、送らない印を付ける
4. 試しの問い合わせを10通作る。うち3通は赤になるはずの物（FAQ に無い料金を聞く・効果を断言させる・関係ない質問）にして、赤が3つ出るかを数えて残す
5. 頁の頭に「見本として作った物（架空の医院）」と書く
```

## ポートフォリオの欄の説明文（相手が読む文・{料金の下限} は問診票から）
```
よくある質問の一覧から、問い合わせへの返事の下書きを作る見本です。架空の歯科医院の FAQ で作りました。
下書きに FAQ に無い金額や言い切りの語が出たときと、どの質問にも当たらないときは、送らずに止める印を付けます。返事を送る前に人が確かめる所だけが残る形です。
同じ規模の仕組みをお受けする場合の目安は、{料金の下限}円からです。
```

## 見せ方
- 公開の頁：問い合わせ→下書き→判定（緑・赤）の並びを10通分の表で
- 画面の画像：赤で止まった3通が見える物
- 動かした記録：赤になるはずの3通が赤になり、通るはずの7通が通った数（3／3・7／7 のように）
- 金額の欄が要る場では「同じ規模をお受けする場合の目安」と書いて入れる
