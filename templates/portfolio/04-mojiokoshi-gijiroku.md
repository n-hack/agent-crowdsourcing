# 見本4 文字起こしと議事録

見本として作ったもの（架空の会議の台本を読み上げた音声）。お客様・実績・金額を作らない。

## 題（業種＋目的の形）
- ポートフォリオの題：不動産会社の社内会議の議事録作成（音声の文字起こしから決定事項と宿題を表に）
- ランサーズの題名の欄：「会議の音声から文字起こしと議事録を作成し」で止める

## 中身
- 入力：架空の会議の台本（3人・10分）を、音声の読み上げ（OS の読み上げ機能や声の合成）で音声にした物。実在の人の声・実在の会議の録音は使わない
- 出力：時刻つきの文字起こし・議事録（日時・出席・決まったこと・宿題と担当と期限・次回）
- 確かめ：台本と文字起こしを並べ、違う語を数えて頁に出す（固有名詞の取り違えが出やすい所を見せる）

## 作り方（エージェントへそのまま渡す指示文）
```
ポートフォリオの見本として、会議の音声から文字起こしと議事録を作ってください。
1. 架空の不動産会社の会議の台本を書く（3人・10分・人の名前は架空。決まったことを3つ、宿題を3つ入れる）
2. 台本を読み上げの機能で音声にする（実在の人の声をまねない）
3. 手元で動く文字起こしの道具で時刻つきの文字起こしを作る
4. 台本と文字起こしを並べ、違った語の数と例を5つ出す
5. 文字起こしから議事録を作る：日時・出席・決まったこと・宿題（担当・期限）・次回。台本にある決まったこと3つと宿題3つが全部入ったかを数えて出す
6. 頁の頭に「見本として作った物（架空の会議）」と書く
```

## ポートフォリオの欄の説明文（相手が読む文・{料金の下限} は問診票から）
```
会議の音声から、時刻つきの文字起こしと議事録を作る見本です。架空の会議の台本を読み上げた音声を使いました。
議事録には決まったことと宿題（担当と期限）を表にし、台本と文字起こしの違いも数えて出しています。
同じ長さの音声をお受けする場合の目安は、{料金の下限}円からです。
```

## 見せ方
- 公開の頁：議事録の全文・文字起こしの先頭の1分・台本との違いの数
- 音声も置く（架空の台本の読み上げと明記）
- 動かした記録：決まったこと3／3・宿題3／3 が拾えたか
- 金額の欄が要る場では「同じ規模をお受けする場合の目安」と書いて入れる
