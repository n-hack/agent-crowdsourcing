# 見本2 Excel の自動集計（小売店の月次売上レポート・架空）

**見本として作った物です。店（見本店A〜C）・商品（商品01〜10）・数字はすべて架空で、乱数で作りました。実在の店・会社・個人・依頼主のデータは使っていません。**
作り方と見せ方の型は [templates/portfolio/02-excel-shuukei.md](../../templates/portfolio/02-excel-shuukei.md)。

## 置いてある物
| ファイル | 中身 |
|---|---|
| shuukei.py | CSV を読んで report.xlsx を作り、最後に合計を突き合わせる道具（Python 3 と openpyxl） |
| data/ | 架空の売上 CSV 30日分（2026-09-01〜30・1日15行・計450行） |
| report.xlsx | 出来上がり。シートは 集計・明細・店別・商品別・日別（折れ線グラフつき） |

## 使い方（3行）
1. 毎日の売上 CSV（列：日付・店・商品・数量・単価・金額）を data/ に置く（試すだけなら `python3 shuukei.py tsukuru` で架空の30日分ができる）
2. `python3 shuukei.py` を打つ
3. report.xlsx ができ、最後に「元の CSV の合計」と「表の合計」が並んで出る。1円でも違えば rc=1 で止まり、渡さない

## 表の作り（値を書き込まず、数式で動く）
店別・商品別・日別の各行は `SUMIFS`、合計は `SUM`、集計シートは3つの表が明細と合うかを `IF` で出します。明細に行を足して数式の範囲を広げれば、表計算ソフトの中でそのまま計算し直されます。Google スプレッドシートでも同じ関数で開けます。
```
[集計]
項目 | 値
月の合計（明細） | =SUM(明細!$F$2:$F$451)
店別の合計 | =店別!B5
商品別の合計 | =商品別!B12
日別の合計 | =日別!B32
3つの表が明細と合うか | =IF(AND(B3=B2,B4=B2,B5=B2),"合う","合わない")
注 | 見本として作った物です。店も数字も架空です
[店別]
店 | 金額
見本店A | =SUMIFS(明細!$F$2:$F$451,明細!$B$2:$B$451,A2)
見本店B | =SUMIFS(明細!$F$2:$F$451,明細!$B$2:$B$451,A3)
見本店C | =SUMIFS(明細!$F$2:$F$451,明細!$B$2:$B$451,A4)
合計 | =SUM(B2:B4)
```
日付は文字ではなく日付の値で持たせています（日別の SUMIFS の条件が型の違いで外れないように）。
