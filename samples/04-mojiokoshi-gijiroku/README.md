# 見本4 文字起こしと議事録（不動産会社の社内会議・架空）

**見本として作った物です。会議・会社（みほん不動産）・人の名前（青木・森・川口）はすべて架空の台本で、実在の会社・個人・依頼主のデータは使っていません。** 音声は、台本を Mac の読み上げ機能（say・日本語の合成の声）で読ませて作った物で、実在の人の声・実在の会議の録音は使っていません。
作り方と見せ方の型は [templates/portfolio/04-mojiokoshi-gijiroku.md](../../templates/portfolio/04-mojiokoshi-gijiroku.md)。この見本は「文字起こしから決まったこと・宿題（担当・期限）を抜き出し、台本の正解と照らして何個拾えたかを数える」ことを見せるための物です（型は10分だが、この見本は4分47秒）。

## 置いてある物
| ファイル | 中身 |
|---|---|
| daihon.json | 架空の会議の台本（3人・45台詞）と、台本を書いた側が決めた正解（決まったこと3つ・宿題3つ） |
| onsei.py | 台本を say で読ませて1本の音声にする（`--nuku 台詞id` で1台詞を抜いた壊れた回を作る） |

| mojiokoshi/kaigi.json | 手元の文字起こし（mlx-whisper・whisper-large-v3-turbo）の出力 |
| mojiokoshi/kowashi.json | 決まったことの台詞 s21 を抜いた音声の文字起こし（壊れた回） |
| gijiroku.py | 文字起こしから議事録を作り、台本の正解と照らして拾えた数を出す（Python 3 の標準だけで動く） |
| yougo.json | 用語の直し表（2語） |
| gijiroku/kaigi.md・kaigi.jikoku.txt | 出来上がりの議事録と、時刻つきの文字起こし（用語の直しを当てた後） |
| gijiroku/kowashi.md・kowashi.jikoku.txt | 壊れた回の議事録 |

## 抜き出しの決まり（gijiroku.py）
抜き出しは文字起こしの文だけを見て行い、台本の正解（daihon.json の kotae）は数えるときだけ使います。
- 決まったこと：「決定」「決めます」「決まりました」を含む文（「次回に決めましょう」のような先送りは拾わない）
- 宿題：「◯◯さん」と「◯月◯日までに」を両方含む文。担当＝「さん」の前の名前、期限＝その日付
- 宿題が拾えたと数えるのは、中身の語・担当・期限の3つとも正解と合ったときだけ
- 正解に無いのに拾った物も数えて出す
- rc：0＝全部拾えた ／ 1＝拾えなかった物がある ／ 2＝入力が読めない

## 動かし方
```
python3 onsei.py                                  # 台本 → kaigi.m4a（macOS の say と ffmpeg が要る）
mlx_whisper kaigi.m4a --model mlx-community/whisper-large-v3-turbo --language ja \
  --output-format json --output-dir mojiokoshi     # 文字起こし（手元で動く・外の API は使わない）
python3 gijiroku.py mojiokoshi/kaigi.json --yougo yougo.json

# 壊れた回（決まったことの台詞 s21 を抜く）
python3 onsei.py --nuku s21 -o kowashi.m4a
mlx_whisper kowashi.m4a --model mlx-community/whisper-large-v3-turbo --language ja --output-format json --output-dir mojiokoshi
python3 gijiroku.py mojiokoshi/kowashi.json --yougo yougo.json
```
Apple シリコンでない機械では、mlx_whisper の代わりに `whisper kaigi.m4a --model turbo --language ja --output_format json --output_dir mojiokoshi`（openai-whisper）も使えるはずです（その JSON も segments に start・text を持つ形。ただしこの見本では openai-whisper では回していません）。この見本で使ったのは mlx_whisper で、4分47秒の音声の文字起こしは12秒でした（time の実測）。

「分かれて」が「別れて」になっているなど、議事録に効かない聞き違いは直していません（2回目の「台本との違い」17か所に入っています）。

## 見ていない範囲
- 声は OS の合成の声だけで、人の声・雑音・話の重なり・言いよどみのある音声では試していない（実際の会議より聞き取りやすい）
- 話し手の見分け（誰が言ったか）はしていない。議事録の担当は文の中の「◯◯さん」から取っている
- 抜き出しの決まりは、この台本の言い方（「決定します」「◯月◯日までに」）に合わせてある。違う言い方の会議では拾えない物が出る
- 正解と照らす語（daihon.json の kotae の go）も台本を書いた側が決めた物で、別の人が決めれば数は変わりうる
