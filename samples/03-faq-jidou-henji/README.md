# 見本3 問い合わせ FAQ の自動返答（歯科医院・架空）

**見本として作った物です。医院（見本デンタルクリニック）・駅・FAQ の中身はすべて架空で、実在の医院・会社・個人・依頼主のデータは使っていません。**
作り方と見せ方の型は [templates/portfolio/03-faq-jidou-henji.md](../../templates/portfolio/03-faq-jidou-henji.md)。

## 置いてある物
| ファイル | 中身 |
|---|---|
| faq.json | 架空の歯科医院の FAQ 20問（問い・選ぶための語・答え） |
| henji.py | 問い合わせから FAQ を選び、その答えの文だけで返事の下書きを作り、危ない下書きを赤にする（Python 3 だけで動く） |

## 作り
- 選び方：FAQ ごとの「選ぶための語」が問い合わせにいくつ入っているかを数え、当たった語の字数の合計がいちばん大きい FAQ を使う。どの語も当たらなければ下書きを作らない
- 下書きは FAQ の答えの文だけを使う（新しい事実・金額を足さない）
- 止める印（赤）は AI ではなく式で当てる。赤は送らずに人へ回す
  - どの FAQ にも当たらない
  - 金額を聞かれているのに、使った FAQ に金額が無い／下書きに FAQ に無い金額（数字＋円）がある
  - 下書きに言い切りの語（必ず・絶対・治ります・保証・確実・100%）がある／問い合わせが言い切りを求めている
- 下書きを人や AI が手直しした後も、同じ検査（`kensa()`）を通せる

## 動かし方
```
python3 henji.py "駐車場はありますか？いくらかかりますか"   # 緑なら rc=0・赤なら rc=1
python3 henji.py tameshi                                     # 試しの10通と、手直しで壊した下書き2通を流して数える
```

## 試しの10通の数（2026-11-06・`python3 henji.py tameshi` の最後・rc=0）
```
=== 数
赤になるはずの問い合わせ … 3／3 が赤
緑になるはずの問い合わせ … 7／7 が緑
手直しで危ない語を足した下書き … 2／2 が赤
✅ 全部はずの通り
```
赤になったのは「ホワイトニングの料金はいくらですか」（FAQ に金額が無い）・「ホワイトニングをすれば必ず白くなりますか」（言い切りを求めている）・「近くでおすすめのランチのお店はありますか」（どの FAQ にも当たらない）の3通です。10通それぞれの下書きと判定は `python3 henji.py tameshi` でそのまま出ます。

## 見ていない範囲
- 選び方は語の照らし合わせだけなので、言い回しが FAQ の語から離れた問い合わせ（例：「痛くて」は「痛い」と別の語になる）は外れることがある。外れたときは赤（どの FAQ にも当たらない）か、違う FAQ を選ぶ。違う FAQ を選んだときは式では止まらないので、送る前に人が読む前提です
- 試しの問い合わせは10通だけ。本物の問い合わせの言い回しでは測っていない
- 画面の画像はまだ撮っていない
