# 見本1 会社リストの CSV（製造業の営業リスト・架空）

**見本として作った物です。会社名・所在地・郵便番号・URL はすべて架空で、実在の会社・個人・依頼主のデータは使っていません。** URL は見本用に予約されたドメイン（example.com）だけを使っています。
作り方と見せ方の型は [templates/portfolio/01-kaisha-list-csv.md](../../templates/portfolio/01-kaisha-list-csv.md)。本番では型のとおり、公開の法人データを利用規約を確かめてから使います。この見本は「列の型・重なりの消し方・数え方・止まり方」を見せるための物です。

## 置いてある物
| ファイル | 中身 |
|---|---|
| make_list.py | 架空の元データ23行から、表記をそろえ・重なりを消し・列の型を確かめて CSV を書く（Python 3 だけで動く） |
| kaisha_list.csv | 出来上がり 20行（UTF-8） |
| kaisha_list_bom.csv | 同じ中身の BOM 付き（Excel で開いても文字化けしない） |
| kazoekata.txt | 元の件数から何件に絞ったかの数え方 |

## 動かし方
```
python3 make_list.py            # 正常な回（rc=0）
python3 make_list.py --kowasu   # わざと型の外れた行を混ぜる回（止まって rc=1・CSV は書かない）
```

## 列の型（確かめの印は最後の「確かめ」の列・全行 OK でなければ CSV を書かない）
| 列 | 型（式） | 意味 |
|---|---|---|
| 会社ID | `K\d{4}` | 「K」＋数字4桁・重なりなし（見分けの列） |
| 会社名 | 空でない | |
| 都道府県 | `(愛知\|岐阜\|三重\|静岡)県` | 絞った4県のどれか |
| 業種 | `製造業` | 絞った業種の語 |
| 郵便番号 | `\d{3}-\d{4}` | 半角の 3桁-4桁（全角は半角にそろえてから見る） |
| 所在地 | 空でない | |
| WebサイトURL | `https://[a-z0-9-]+\.example\.com/` | 見本用のドメインだけ |
| 従業員数 | `[1-9]\d{0,4}` | 半角の整数 |
| 取得元 | 空でない | |
| 取得日 | `\d{4}-\d{2}-\d{2}` | YYYY-MM-DD |
| 確かめ | `OK` か `NG:外れた列` | 上の型を全部満たせば OK |

個人の名前・メールアドレス・電話番号の列は作りません（公開の情報でも営業の連絡先として集めない）。

## 動かした記録（2026-11-06）
正常な回（rc=0）
```
元の行数 23
重なりで消した行 3（同じ会社IDの2行目以降）
残った行 20 ＝ 23 − 3
確かめ OK 20 行 ／ NG 0 行
数え方：会社IDを見分けの列にし、出てきた順で最初の1行を残す。表記は NFKC で全角を半角にそろえ、前後の空白を消してから確かめる
✅ 全行が列の型どおり
```
わざと壊した回（ドメインが example.net・郵便番号が1桁足りない行を混ぜた・rc=1）
```
元の行数 24
重なりで消した行 3（同じ会社IDの2行目以降）
残った行 21 ＝ 24 − 3
確かめ OK 20 行 ／ NG 1 行
🔴 K0021 NG:郵便番号/WebサイトURL
🔴 確かめで止めた（NG の行がある CSV は渡さない）
```
